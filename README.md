Healthcare Operations & Revenue Analytics Dashboard

📊 Project Overview
This project focuses on analyzing healthcare data using Excel to understand hospital performance, patient trends, and revenue patterns. 
The dashboard is built using Power Query and Power Pivot to clean, transform, and model data from multiple sources.



🛠️ Tools Used
- Microsoft Excel  
- Power Query (Data Cleaning & Transformation)  
- Power Pivot (Data Modeling)  
- Pivot Tables & Charts  


📁 Dataset Description
The dataset consists of three main tables:
- Patient Data  
- Appointment Data  
- Billing Data  

These tables were connected using a data model to enable cross-functional analysis.

🔍 Key Insights

1. The dataset includes around **2000 patients**, generating approximately **₹6.4 Cr (INR) in total revenue**, indicating strong overall healthcare activity.  
2. Apollo Hospital contributes the highest revenue (~₹1.74 Cr)**, followed by Fortis Healthcare, showing variation in hospital performance.  
3. Out-of-pocket payments are nearly equal to insurance-covered amounts**, indicating moderate insurance utilization and reliance on direct patient payments.  
4. Patient trends fluctuate over time**, suggesting inconsistent inflow and potential operational planning challenges.  
5. Telangana and Maharashtra have the highest patient concentration**, indicating stronger demand in these regions.  
6. Presence of **'Unknown' values in insurance data** highlights data quality gaps that can impact analysis.  

🎯 Business Decisions

Focus on improving **service quality and operational consistency** across hospitals.  
Increase **insurance adoption** to reduce dependency on out-of-pocket payments.  
Optimize **staffing and resources based on patient demand trends**.  
Strengthen **healthcare services in high-demand regions** like Telangana and Maharashtra.  
Improve **data collection practices** to ensure more accurate and reliable analysis.  

📌 Conclusion
This dashboard helps in understanding key healthcare metrics, identifying performance gaps, and supporting data-driven decisions to improve both operational efficiency and patient experience.
